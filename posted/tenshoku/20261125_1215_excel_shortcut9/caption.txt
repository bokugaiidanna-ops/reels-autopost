表作りが一気に速くなるショートカット9個。

① Ctrl + A …表の中で押すと表全体を選択
② Ctrl + T …テーブルに変換（色・フィルターつき）
③ Alt → H → B …罫線メニュー（格子を選ぶ）
④ Ctrl + Shift + 6 …外枠の罫線（英語配列は Ctrl + Shift + &）
⑤ Alt → H → A → C …中央そろえ
⑥ Ctrl + B …太字
⑦ Ctrl + ; …今日の日付を入力
⑧ F4 …直前の操作をくり返す
⑨ Alt + F1 …選んだデータからグラフを作成

※「→」は順番に押す、「+」は同時に押すキーです（Windows版Excel）

出典：Microsoft サポート「Excel のキーボード ショートカット」、Microsoft 法人向けコラム「Excel のショートカットキー」
