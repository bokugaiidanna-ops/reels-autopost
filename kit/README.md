# 型キット（reelkit）

台本（JSON）を書くと、場面ごとに「型」を選んで縦型リール（1080×1920・30fps）が組み上がる。
どんなネタでも、下の型を組み合わせれば作れる。

## 使い方
1. 作業フォルダに `script.json` を書く（例：`kit/sample_script.json`）
2. 声を入れるなら、各シーンの `voice` を Speko（Gemini TTS・声 Charon）で1行ずつ作り、
   無音カット＋`atempo=1.4` して `audio/<シーンid>.wav` に置く
3. `python3 kit/reelkit.py script.json out_A.mp4 --hook A`（B・Cも同様）
4. 確認は `--stills 1.0,5.0` で静止画だけ書き出して見る
- シーンの長さ＝声の長さ＋0.55秒。声がなければ `dur` 秒
- `theme`：seiseiai / okane / default（アクセント色とアカウント名）
- `source` を書くと全シーンの下に出典が出る

## 型の一覧とネタとの相性
| 型 | 見た目 | 向いてるネタ |
|---|---|---|
| title | 大きい文字のフック | 冒頭（A/B/Cテスト） |
| bars | 横棒が伸びる | 確率・割合・2〜5個の比較 |
| cards | カードが1枚ずつ出る | 料金・プラン比較、3択 |
| chat | チャット画面＋「それ、ウソ！」 | AIの失敗・実験・聞き方で答えが変わる |
| zoom | 円がズームアウト | 大きさ・量の差で驚かせる（何倍） |
| people | 100人の棒人間が色分け | 「100人のうち何人」系の割合 |
| kinetic | 文字だけ跳ねる | 結論・言い切り・テンポを上げたい所 |
| tier | ティア表が埋まる | ランキング・おすすめ度 |
| network | 光るネットワーク | AIの中で何が起きてるか（しくみ） |
| noise | 砂嵐→絵 | 画像生成のしくみ |
| point | 結論ボックス | まとめ・得する一言 |
| cta | フォロー・保存 | 最後 |

## 組み方の基本（30秒前後）
冒頭 title → 問い/事実（bars・chat・zoom・people のどれか）→ しくみ（network・bars・kinetic）→ まとめ point → cta

## 注意
- 数字は必ず一次情報で確認。仮の数字のまま出さない
- 実在アプリの画面そっくりにはしない（chatはオリジナルの見た目）
- 既存キャラ・ロゴは使わない
