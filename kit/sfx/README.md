# 効果音（SFX）キット

決定：2026-11-12（ヨウヘイさん）「もしもシリーズは今後、動作に効果音を入れる」

## 使い方（完成した動画に後から足す）
```
python3 kit/sfx/add_sfx.py in.mp4 out.mp4 --auto                 # 動きを見つけて自動で置く
python3 kit/sfx/add_sfx.py in.mp4 out.mp4 --auto --cues cues.json # 自動＋手で指定（指定が優先）
python3 kit/sfx/add_sfx.py in.mp4 out.mp4 --auto --dry           # 置く場所だけ表示して確認
```
cues.json の例：`[{"t":0.05,"s":"tick"},{"t":20.0,"s":"coin"},{"t":9.2,"s":"down","v":0.8}]`（v＝その音だけの音量倍率）

## 自動で置くルール
- 画面全体が切り替わる → whoosh（シュッ）
- 止まっていた画面に何かが出る → pop（ポン）
  - 出たものが緑っぽい（＋の数字・上向き矢印）→ up（ピロン）
  - 赤っぽい（−の数字・悪いニュース）→ down（ブブッ）
- キャラの待機アニメなど、ずっと動いている所は無視する
- 音量は声の下（既定 --vol 0.35）

## 手で足すと良いもの（自動では拾えない）
- カウントダウン 3・2・1 → tick
- お金・収入が出る → coin
- 答え・ひらめき → sparkle
- 言い切り・ドンと出る文字 → thud
- テロップが打たれる → type

## 音について
全部 `gen_sfx.py` で数式から作った自前の音（著作権の心配なし）。作り直すときは `python3 kit/sfx/gen_sfx.py`
